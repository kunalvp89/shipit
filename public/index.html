Environment
Only these two server environment variables are required:
GITHUB_TOKEN
GitHub credential allowed to create private repositories.
SHIPIT_VERCEL_TOKEN
Vercel access token allowed to create projects and production deployments.
Your tokens never reach the browser and are never included in GitHub commits or project files.
